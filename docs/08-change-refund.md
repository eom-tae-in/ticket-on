# 08. 예매 변경 · 취소 · 환불

변경과 취소는 **계산 방식이 같습니다.** 그래서 한 문서에 둡니다.

> **변경 = 취소 + 재예매**

## 법적 기준

공정거래위원회 고시인 **소비자분쟁해결기준**(공연업)을 따릅니다.

| 취소 시점 | 공제율 |
|---|---|
| 관람일 10일 전까지 | 없음 (전액 환급) |
| 9~7일 전 | 10% |
| 6~3일 전 | 20% |
| 2~1일 전 | 30% |
| 당일 (시작 전) | 90% |

예외:

- **예매 직후** — 예매 후 24시간 이내 취소 시, 관람일 3일 전까지라는 조건 아래 공제 없이 전액 환급
- **주최자 쪽 사정** (아래 "주최자 귀책")

| 상황 | 기준 |
|---|---|
| 주최자 사정으로 공연 취소 | 입장료 환급 + **10% 배상** |
| 천재지변 등 불가항력으로 취소 | 입장료 환급 |
| 주최자 사정으로 **30분 이상 지연** | 입장료의 **10% 환급** |
| **주요 출연자 교체**, 예정 시간의 **절반 이하 공연** | 입장료 환급 + **10% 배상** |

> 2026년 10월 기준으로 구간을 확인했습니다. 시행 전 고시 원문으로 재확인하십시오 (`99` 참조).

## 규정은 기준 고정, 관대한 방향만 조정 가능

이 기준은 강제가 아니라 권고입니다. 그래도 **주최자에게 자유롭게 정하게 하면 안 됩니다.**

소규모 주최자가 "환불 불가"로 설정하면 분쟁이 생기고 부담은 플랫폼이 집니다. 관객은 개별 주최자가 아니라 **우리 서비스를 믿고** 예매합니다.

> 기준을 기본값으로 고정하고, 주최자는 **관객에게 더 유리한 쪽으로만** 조정할 수 있습니다.

"공연 3일 전까지 전액 환불" 같은 관대한 설정은 허용, "7일 전부터 환불 불가"는 차단합니다.

**예매가 열린 뒤(판매 중)에는 규정을 바꿀 수 없습니다.** 관객마다 예매 시점의 규정이 따라다닙니다 (`04` 참조). 오픈 전 판매 대기 중에는 예매가 없어 바꿀 수 있습니다.

# 취소

## 관객이 직접, 자동 환불

**주최자 승인제로 하면 안 됩니다.** 승인 권한이 있으면 거부할 수 있고, 그 순간 위 기준이 무의미해집니다.

**취소 전에 환불액을 먼저 보여주고 확인받습니다.**

> 취소하시겠습니까?
> 결제 금액 50,000원 · 취소 수수료 10,000원 (20%)
> **환불 예정 40,000원**

**환불 소요 시간도 안내합니다.** 카드는 며칠, 계좌는 빠릅니다.

## 취소 마감

| | 마감 |
|---|---|
| 회차형 | 회차 시작 전까지 |
| 종일형 | 해당 날짜 시작 전 (전날 자정) |

**종일형은 "시작"이 없습니다.** 아무 때나 들어가는 구조라 전날 자정으로 잡습니다.

**입장 기록이 하나라도 있는 티켓은 취소 불가**입니다. 종일형에서 오전에 들어갔다 나와서 오후에 취소하는 걸 막아야 하고, **묶음권도 첫날 입장하면 전체 취소가 막힙니다.**

## 관리자 대신 취소

**관객이 기한 안에 취소하려 했는데 우리 쪽 오류로 못 한 경우**에만 씁니다.

> 공연 3/15, 3/12 23:50에 취소를 누름(3일 전, 공제 20%) → 서버 오류로 실패 → 23:55에 문의
> → 관리자는 3/13 10시에 처리(이때 기준이면 2일 전, 공제 30%)
> → **문의한 23:55 기준으로 20%를 적용**

| | |
|---|---|
| 관리자가 확인하는 것 | **그 시각에 실제로 오류가 있었는지**만 |
| 환불 금액 | **문의한 시각** 기준의 규정대로. 관리자가 정하지 않음 |
| 관객의 개인 사정 | 보지 않음. 사정에 따라 금액이 달라지지 않음 |
| 회차 시작 후 | 관리자도 취소할 수 없음 (규정과 같음) |
| 취소 사유 | "관리자 조치" (`07` 참조) |

**금액에 재량을 두지 않는 이유** — 관리자가 사정을 듣고 금액을 정하기 시작하면 모든 문의가 협상이 됩니다.

관리자 화면에서 **예매번호나 이메일로 예매를 찾아** 처리합니다 (`13` 참조).

## 부분 취소

**지정석은 좌석을 골라서** 취소합니다. 티켓마다 금액이 다를 수 있으므로 화면에 표시합니다.

> 취소할 좌석을 선택하세요
> ☐ 12열 7번 · 35,000원 (조기예매)
> ☐ 12열 8번 · 35,000원 (조기예매)
> ☑ 12열 9번 · 50,000원
> ☑ 12열 10번 · 50,000원
>
> 환불 예정 **100,000원**

**수량형은 고를 수 없으므로 비싼 것부터** 취소됩니다.

> 취소할 매수: **[2]** 매
> 환불 예정 **100,000원**
>
> ※ 금액이 높은 티켓부터 취소됩니다.

지정석이면 관객이 어차피 비싼 자리를 골라 취소합니다. **수량형이라고 불리하게 대우할 이유가 없습니다.** 고를 수 없는 대신 규칙이 투명해야 합니다.

**묶음권은 전체 취소만** 가능합니다. 하루만 빼면 남은 게 3일권이 아니고 가격 재계산도 답이 없습니다. 공제율 기준일은 티켓이 가리키는 **가장 이른 회차의 날짜**입니다.

**이미 그날 몫을 돌려받은 묶음권**(주최자가 하루를 취소했거나 출연자 변경으로 하루를 포기한 경우)을 나중에 전체 취소하면:

| | |
|---|---|
| 환불 기준액 | **결제 금액 − 이미 환불한 그날 몫.** 같은 돈을 두 번 돌려주지 않음 (아래 "기준 금액") |
| 공제 기준일 · 취소 마감 | **남아 있는 회차** 중 가장 이른 날짜 (취소되거나 포기한 날은 빼고 셈) |
| 이미 받은 10% 배상 | 그대로 둠. 주최자 사정으로 받은 것 |

이건 **관객이 취소할 때** 규칙입니다. 주최자가 그중 하루를 취소한 경우는 아래 "주최자 귀책"을 따릅니다.

## 여러 예매 건을 한 번에 취소

같은 행사를 두 번 나눠 예매했다면 예매 건이 둘입니다. **한 화면에서 골라 요청**하되, 환불은 건별로 나갑니다.

> **3/1 예매 (...0091)**
> ☑ 12열 7번 · 50,000원
> ☑ 12열 8번 · 50,000원
>
> **3/5 예매 (...0134)**
> ☑ 15열 3번 · 50,000원
> ☐ 15열 4번
>
> 환불 예정 **150,000원** (2건으로 나누어 처리)

**마지막 줄이 있어야** 환불이 두 번 들어와도 관객이 당황하지 않습니다.

## 취소 직후

**좌석은 즉시 풀립니다.** 인기 회차에서 취소표를 노리는 관객이 실제로 있습니다.

| | 취소 시 |
|---|---|
| 좌석 | 즉시 복구 |
| 조기예매 몫 | **복구 안 함** (선점 순간 누적, 영구 마감) |
| 쿠폰 — 전체 취소 | **복구** (유효 기간은 그대로) |
| 쿠폰 — 부분 취소 | **복구 안 함** |

**조기예매와 쿠폰의 차이**는 성격입니다. 조기예매는 선착순으로 다투는 자원이고, 쿠폰은 특정 개인에게 준 권리입니다 (`05` 참조).

**부분 취소에서 쿠폰이 복구되지 않는 이유** — 남은 티켓이 아직 그 쿠폰을 쓰고 있습니다. 4매에 쓴 쿠폰을 2매만 취소했으면 쿠폰은 여전히 사용 중입니다.

# 예매 변경

## 계산뿐 아니라 처리도 "취소 + 재예매"입니다

> **변경 = 기존 티켓 환불 (취소 규정대로) + 새 티켓 전액 결제**

차액만 정산하지 않습니다. 돈이 두 번 움직입니다. 기존 티켓은 **지금 취소하는 것과 같은 금액**이 환불되고, 새 티켓은 가격 전부를 냅니다.

> S석 50,000원 → 2일 전 A석 30,000원으로 변경 (공제율 30%)
>
> ```
> 환불   −35,000원     50,000 × 70%
> 결제    30,000원     A석 가격 전액
> ──────────────────────────────────
> 5,000원이 관객에게
> ```

업그레이드도 같습니다.

> S석 50,000원 → VIP 80,000원 (공제율 30%)
>
> ```
> 환불   −35,000원
> 결제    80,000원
> ──────────────────────────────────
> 45,000원 추가 결제
> ```

**금액 결과는 차액 정산과 똑같습니다.** 달라지는 건 기록과 처리입니다.

| 이점 | |
|---|---|
| **티켓 금액이 곧 실제 받은 돈** | 차액만 정산하면 티켓에 적힌 80,000원과 실제로 받은 45,000원이 어긋납니다 |
| 추적 | 환불 한 줄과 결제 한 줄이 각각 남습니다 |
| 설명 | "취소 후 재예매와 정확히 같다"가 말뿐이 아니게 됩니다 |

차액에만 공제율을 적용하는 방식도 검토했으나 계산이 복잡하고 관객에게 설명하기 어려웠습니다. 그리고 이 방식이면 **수수료 회피 경로가 원천 차단**됩니다.

### 관객에게 미리 알려야 합니다

카드 내역에 환불과 결제가 **각각** 찍힙니다. 차액만 움직이는 걸 기대한 관객이 놀랍니다.

> 기존 예매는 환불되고 새로 결제됩니다. 카드 내역에 환불과 결제가 각각 표시됩니다.

## 그럼 변경 기능의 가치는

돈은 같은데 **안전과 편의**가 다릅니다.

- 취소 후 재예매하면 **그 사이 원하는 자리가 팔릴 수 있습니다.** 변경은 기존 좌석을 쥔 채 새 좌석을 선점하니 그 위험이 없습니다
- 두 번 할 일이 한 번에 끝납니다
- **10일 전까지는 공제가 0**이므로 대부분의 변경은 손해가 없습니다

## 공제율은 항상 기존 회차 기준

> 3/20 공연을 3/14 공연으로 변경, 오늘은 3/10
>
> **기존 회차(3/20) 기준 → 10일 전 → 공제 0%**

취소하는 건 3월 20일 예매고 그 시점에 공제율이 결정됩니다. 3월 14일 공연은 아직 사지도 않았으니 공제 대상이 될 수 없습니다.

**반대 방향도 같습니다.** 3/14를 3/20으로 미루면 기존 회차(3/14) 기준이라 관객에게 불리하지만, **일관성이 우선**입니다. 유리할 때만 기존 기준으로 하면 임박한 공연을 먼 공연으로 바꿔 공제를 피하는 길이 열립니다.

**화면에 어느 날짜로 계산했는지 표시**합니다.

## 규칙

| 항목 | |
|---|---|
| 범위 | 업그레이드·다운그레이드 모두 |
| **부분 변경** | **가능** — 4매 중 1매만, 또는 고른 만큼 한 번에 |
| 횟수 | **제한 없음** |
| 기한 | **예매 종료 시각까지** |
| 변경 수수료 | 없음 (취소 공제가 전부) |
| 새 좌석 가격 | **변경 시점의 현재 가격** |
| 묶음권·초대권 | 변경 불가 |
| 기존 QR | 확정 즉시 **무효**, 새 QR 발급 |
| 티켓 | 기존 티켓은 **취소됨**, 새 티켓 발급 |
| 이력 | **예매 건의 결제·환불 내역**이 가짐 |

**기한이 취소보다 짧습니다.** 취소는 법적으로 공연 시작 전까지 가능하지만, 변경은 우리 재량이고 예매 종료 이후에는 주최자가 현장 준비에 들어갑니다.

**새 좌석 가격은 지금 시점 가격**입니다. 조기예매가 끝났으면 정가입니다. 예전 가격을 끌고 오면 변경을 반복하며 영원히 할인가를 유지하게 됩니다.

**쿠폰은 복구되지 않고 그대로 따라갑니다.** 예매가 이어지니까요. 정액 쿠폰은 매수가 줄면 몫도 줄어드는데, 티켓 단위 기록을 쓰니 자동으로 계산됩니다.

**새 티켓에 쿠폰을 적용하는 법**

| 쿠폰 | 새 티켓 |
|---|---|
| 정률 (20%) | 새 가격에 **같은 비율** |
| 정액 (5,000원) | 기존 티켓에 나눠 둔 **금액 그대로** (새 가격을 넘지 않게) |
| 유효 기간 | 보지 않음. 새로 쓰는 게 아니라 이미 쓴 쿠폰을 옮기는 것 |
| 조기예매와 비교 | 평소처럼 **유리한 하나** — 옮겨온 쿠폰과 지금 받을 수 있는 조기예매 중 (`05` 참조) |

변경했다고 쿠폰 혜택을 잃으면 관객은 변경 대신 취소 후 재예매를 하고, 그 사이 자리를 놓칩니다 (`15` 한서윤).

## 티켓에 "변경됨" 상태를 두지 않습니다

변경하면 **기존 티켓은 취소되고 새 티켓이 생깁니다.** 둘을 잇는 이력은 **예매 건의 결제·환불 내역**이 가집니다.

```
예매 건 ...0091
 3/1  결제   165,000원
 3/5  환불   −35,000원   12열 10번 취소
 3/5  결제    30,000원   15열 3번
```

티켓마다 "이 티켓은 저 티켓에서 바뀐 것"을 들고 다니게 하면, 여러 번 변경한 티켓이 사슬이 되어 추적이 복잡해집니다. 내역 한 곳에 모으면 **부분 취소와 부분 변경이 같은 방식으로 읽힙니다.**

## 부분 변경과 여러 장 동시 변경

4매 중 2매를 나란히 옮기는 경우, **고른 만큼 한 번에** 처리합니다.

```
변경할 좌석을 선택하세요
☐ 12열 7번
☐ 12열 8번
☑ 12열 9번
☑ 12열 10번

→ 2석을 고를 차례
```

한 장씩만 되면 **중간에 자리를 놓칩니다.** 15열 3번을 잡는 동안 4번을 다른 사람이 가져가면 나란히 앉으려던 목적이 깨집니다. 환불과 결제도 두 번씩 일어나고요.

**나머지 티켓은 건드리지 않습니다.** 공제도 변경하는 티켓에만 붙습니다.

## 변경 중에는 기존 좌석을 유지합니다

```
기존 좌석 유지
  → 새 좌석 선점 (타이머 10분)
  → 기존 티켓 환불 + 새 티켓 결제
  → 확정되는 순간 기존 좌석 해제
```

새 자리를 고르는 동안 기존 자리를 먼저 풀면 **둘 다 잃을 수 있습니다.**

## 화면에 계산을 그대로 보여줍니다

> **좌석 변경**
> 현재 예매: S석 12열 7번 · 50,000원
> 지금 취소 시 환불액: **35,000원** (관람일 2일 전, 30% 공제)
>
> 변경할 좌석: A석 5열 3번 · 30,000원
> → **5,000원이 환불됩니다**
>
> ※ 취소 후 다시 예매하는 것과 동일한 금액입니다.

마지막 줄이 없으면 "변경했더니 돈을 떼였다"는 문의가 옵니다.

## 기준 금액

**항상 실제 결제액 기준**입니다. 조기예매가 3만원을 냈으면 그 3만원이 기준이고, 여러 번 변경한 경우도 누적이 아니라 **현재 유효한 결제액**이 기준입니다. 일부를 이미 돌려받았으면(묶음권 그날 몫, 공연 지연 환급) 그만큼 뺀 금액이 기준입니다.

## 공제 면제가 붙은 티켓

연기·장소 변경·회차 시간 수정·출연자 변경으로 붙습니다 (`04` 참조).

변경해도 **면제가 새 티켓에 승계**됩니다. 연기 때문에 자리를 옮기는 경우가 많은데, 옮기는 순간 면제를 잃으면 연기 피해자가 두 번 손해를 봅니다.

**출연자 변경의 10% 배상은 승계되지 않습니다.** 배상은 그 회차를 **포기하고 취소할 때만** 붙습니다. 다른 회차로 바꾼 사람은 원하던 공연을 보러 가는 것이라 배상할 이유가 없습니다.

**면제는 공제에만 적용되고 차액에는 적용되지 않습니다.**

> 연기된 공연 · S석 50,000원 (면제)
> → VIP 80,000원으로 변경
>
> 환불 기준액 **50,000원** (공제 0%)
> VIP 가격 80,000원
> → **30,000원 추가 결제**

# 결제·환불 내역

## 돈이 움직일 때마다 영수증이 하나씩

```
예매번호 ...0091
3/1  결제    165,000원   [상세]
3/5  환불    −35,000원   [상세]  2매 취소
3/8  환불    −50,000원   [상세]  12열 10번 변경
3/8  결제     30,000원   [상세]  15열 3번
───────────────────────────────
실 결제액 110,000원
```

**변경은 환불 한 줄과 결제 한 줄로 나타납니다.** 차액 한 줄로 적으면 어느 티켓이 어떻게 바뀌었는지 사라집니다.

**부분 취소와 부분 변경이 여러 번 일어나도 전부 추적됩니다.** 한 장짜리 내역만 있으면 중간 변경이 어디로 갔는지 알 수 없습니다.

**적용된 할인도 여기 표시**합니다. 조기예매와 쿠폰 중 유리한 걸 자동으로 고르므로 (`05` 참조), 관객이 무엇이 적용됐는지 알아야 합니다.

## "영수증"이라 부르지 않습니다

세금계산서와 현금영수증은 만들지 않습니다 (`11` 참조). "영수증"이라고 쓰면 그걸 기대하게 됩니다.

**화면 이름은 "결제·환불 내역", 개별 항목은 "결제 상세"** 입니다.

# 주최자 귀책

**회차 취소**와 **행사 취소** 모두 해당 예매자 전원이 **자동 전액 환불**되고 통지가 나갑니다. 공제는 없습니다. 둘 다 소유자만 할 수 있고, 흐름은 `04`에 있습니다.

**행사 취소는 아직 시작하지 않은 회차만** 취소합니다. 이미 공연한 회차는 환불하지 않고 정산합니다 (`04` 참조).

**회차 취소는 관객을 다른 회차로 옮기지 않습니다.** 다른 날로 옮기려면 연기를 씁니다 (`04` 참조).

10% 배상은 주최자 부담이고 **정산에서 뺍니다** (`11` 참조). 테스트 결제 환경이라 실제 송금은 없습니다. 화면 흐름만 만듭니다.

**불가항력(천재지변, 정부의 공연 금지 조치)이면 배상이 없습니다.** 취소할 때 사유를 고르고, 배상은 관리자가 확인할 때까지 보류합니다. 환불은 기다리지 않습니다 (`04` 참조).

**주최자 자발적 취소와 관리자 정지 3단계는 처리가 같고 기록만 다릅니다** (`04` 참조).

**연기는 취소가 아닙니다.** 공제 면제가 붙고 배상은 없습니다 (`04` 참조).

취소된 티켓에는 사유가 붙고 예매 카드에 회색으로 남습니다 (`07` 참조). 관객이 알림을 못 봤어도 예매 내역을 열면 바로 압니다.

## 묶음권 중 하루가 취소되면

> 페스티벌 3일권(5/3~5/5)을 샀는데 주최자가 5/4만 취소했습니다.

**티켓은 그대로 두고 그날 몫만 환불하고 10% 배상합니다** (불가항력이면 배상 보류, `04` 참조). 남은 이틀은 그대로 들어갑니다.

> **그날 몫 = 티켓 결제 금액 × 그날 가격 ÷ 날짜별 가격 합계** (원 미만 버림)
>
> 그날 가격은 티켓이 가리키는 그 날 회차의 가격입니다. 같은 날 회차끼리 가격이 다르면 관객이 고른 회차 가격입니다 (`05` 참조).

```
3일권: 금 40,000 + 토 50,000 + 일 50,000 = 140,000원 → 7% 할인 → 130,200원

토요일(5/4) 취소
  환불  130,200 × 50,000 ÷ 140,000 = 46,500원
  배상  46,500 × 10%              =  4,650원
```

**실제로 낸 돈이 기준**입니다. 쿠폰이나 조기예매를 썼으면 그만큼 줄어든 금액을 날짜별 가격 비율로 나눕니다.

```
3일권 94,500원 (1일권 35,000 × 3, 10% 할인) − 쿠폰 5,000원 = 89,500원 결제

둘째 날 취소
  환불  89,500 × 35,000 ÷ 105,000 = 29,833원
  배상  29,833 × 10%              =  2,983원
```

> 처음에는 "그날 가격 × (1 − 할인율)"이었으나, 쿠폰을 쓴 관객에게 낸 것보다 많이 돌려줄 수 있어 실제 결제 금액 기준으로 바꿨습니다. 쿠폰이 없으면 두 공식은 같은 값입니다.

**3분의 1로 나누지 않는 이유** — 날마다 가격이 다르면 어느 날이 취소되느냐에 따라 한쪽이 손해를 봅니다.

| 취소된 날 | 3분의 1 | 그날 가격 |
|---|---|---|
| 금 (싼 날) | 43,400원 — 주최자가 6,200원 더 냄 | 37,200원 |
| 토 (비싼 날) | 43,400원 — 관객이 3,100원 덜 받음 | 46,500원 |

묶음권 가격을 "날짜별 가격을 더한 뒤 할인"으로 정했으므로 (`05` 참조), 하루 몫도 같은 방식으로 빼는 게 맞습니다. **날마다 가격이 같으면 두 방식은 같은 값**입니다.

**첫날 이미 입장했어도 둘째 날 몫은 환불됩니다.** "입장 기록이 있으면 취소 불가"는 관객이 취소할 때 규칙이고, 이건 주최자가 날린 날입니다.

티켓은 여전히 세 회차를 가리키고, 5/4에 찍으면 회차가 취소됐으므로 검표에서 거부됩니다 (`07` 참조).

**출연자가 바뀐 날을 관객이 포기할 때도 같은 그날 몫 + 10% 배상**입니다. 이때는 티켓의 그 날짜 회차에 **"포기" 표시**가 붙습니다 (`04`, `07` 참조).

## 공연 지연

> 19:30 공연이 무대 장비 문제로 20:15에 시작했습니다 (`15` 한서윤).

**주최자 사정으로 30분 이상 늦게 시작하면 입장료의 10%를 돌려줍니다.**

```
[공연 지연 처리] (소유자, 회차 화면)
  → 실제 시작 시각 입력 → 예정보다 30분 이상 늦었는지 확인
  → 그 회차에 입장한 티켓마다 결제 금액의 10% 환급
     (묶음권은 그날 몫의 10%)
  → 결제·환불 내역에 "공연 지연 환급" 한 줄, 이메일
```

| 규칙 | |
|---|---|
| 대상 | **그 회차에 입장 기록이 있는 티켓.** 오지 않은 사람은 기다리지 않았음 |
| 티켓 | 그대로 유효. 취소가 아님 |
| 30분 미만 | **처리 없음.** 소극장의 5~10분 늦은 시작은 대상이 아님 (`15` 박정훈) |
| 기한 | **그 행사 정산 완료 전, 그리고 행사 종료 30일 이내** (대상을 정하는 입장 기록이 30일 뒤 삭제됨, `10` 참조) |
| 비용 | 주최자. 정산에서 뺌 (`11` 참조) |
| 주최자가 안 하면 | 관객 신고 → 관리자가 주최자에게 확인 후 **대신 처리** (`01` 참조) |

**지연 처리에는 불가항력 선택이 없습니다.** 기준이 "주최자 사정으로 지연"일 때만 환급을 정하므로, 주최자 사정이 아니면 처리하지 않습니다. 다툼이 있으면 관객 신고로 관리자가 봅니다.

## 공연 중단

> 공연 시작 40분 만에 정전으로 멈췄습니다. 예정은 2시간입니다.

**예정 공연 시간의 절반 이하만 하고 멈추면** 그 회차를 취소한 것과 같게 처리합니다.

| 규칙 | |
|---|---|
| 누가 | **소유자** — [공연 중단 처리] (회차 시작 후 ~ 정산 완료 전) |
| 사유 | 주최자 사정 / 불가항력 — 회차 취소와 같음 (`04` 참조) |
| 판정 | 회차의 시작~종료 시각으로 절반을 봄 (`02` 참조). 종일형은 운영 시간 |
| 대상 | **그 회차 유효 티켓 전원.** 입장 여부 무관 |
| 환불 | **전액 + 10% 배상.** 불가항력이면 배상 보류 (`04` 참조) |
| 취소 사유 | **"공연 중단"** (`07` 참조) |
| 묶음권 | 그날 몫 + 10% 배상(불가항력이면 보류), 티켓은 유지 |
| **절반 넘게 공연한 뒤** | 기준에 없으므로 **처리하지 않음** |

**절반 넘게 하고 멈춘 경우를 두지 않는 이유** — 소비자분쟁해결기준에 기준이 없습니다. 우리가 따로 정하면 주최자마다 다르게 받아들여 다툼만 늘어납니다.

## 출연자 변경

주요 출연자가 바뀌면 **그 회차 표에 공제 면제 + 취소 시 10% 배상**이 붙습니다. 흐름과 묶음권의 "그날만 포기"는 `04`에 있습니다.

|---|---|
| 관객이 취소하면 | 공제 0% + 10% 배상 (주최자 부담) |

| 관객이 다른 회차로 바꾸면 | 공제 0%, 배상 없음 (위 "공제 면제가 붙은 티켓") |
| 그냥 보러 가면 | 아무 일 없음 |

미성년자가 나이를 속여 예매하고 현장에서 막히는 상황은 반드시 생깁니다.

**관객 귀책이므로 환불 대상이 아닙니다.** 다만 **사전 고지가 명확해야** 합니다. 행사 페이지와 예매 확인 화면 양쪽에 "연령 미달 시 입장이 거부되며 환불되지 않습니다"가 있어야 분쟁에서 설명이 됩니다.
