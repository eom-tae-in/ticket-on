# 03. 행사 설정

## 기본 정보

| 필드 | |
|---|---|
| 제목 | 필수 |
| 유형 | **공연 / 전시 / 페스티벌.** 필수. 관객 화면의 이름과 목록 필터에 쓰임 |
| 카테고리 | 유형별 목록에서 선택 (아래 참조) |
| 소개 | 필수 |
| 포스터 | **3:4 세로 고정** |
| 공연장 이름 | ○○아트홀 |
| 주소 | 필수 |
| 상세 안내 | 선택. "지하 1층", "주차 불가" 등 |
| 지도 링크 | 선택. 외부 지도 주소 |
| 공개용 연락처 | 선택. 적으면 행사 페이지에 노출 |

**회차 방식(회차형 / 종일형)은 여기서 고르지 않습니다.** 유형과 다른 축이라 회차를 만드는 2단계에서 고릅니다 (`02` 참조).

**지도 API를 임베드하지 않습니다.** 비용과 복잡도에 비해 얻는 게 적습니다. 주소를 눌렀을 때 외부 지도 앱으로 연결되는 정도면 충분합니다.

**포스터는 3:4 세로 고정**입니다. 비율이 제각각이면 목록 카드가 지저분해집니다. 업로드 후 크롭 도구를 제공하고 용량 상한을 둡니다.

### 제목 · 소개 · 포스터는 변경 이력을 남깁니다

예매가 열린 뒤에도 자유롭게 바꿀 수 있지만(`04` 참조), **덮어쓰면 안 됩니다.**

> 3/1 — "주연: 김배우"로 등록
> 3/5 — 관객 A가 예매
> 3/10 — "주연: 이배우"로 수정
> 3/12 — A가 항의 "김배우 보려고 샀는데요?"

**주요 출연자 교체는 환불 사유입니다** (소비자분쟁해결기준). 현재 버전만 남아 있으면 **A가 뭘 보고 샀는지 확인할 방법이 없습니다.**

주최자는 소개 글을 고치는 것과 별개로 **[출연자 변경 알림]** 을 보내야 합니다. 그 회차 기존 예매자에게 공제 없는 취소와 10% 배상 권리가 생깁니다 (`04` 참조). 주최자가 알리지 않아 관객이 신고하면 **관리자가 이 이력으로 확인**하고 대신 처리합니다.

**회차별 출연 칸도 같습니다** (`02` 참조). 더블 캐스팅 관객은 소개보다 이 칸을 보고 삽니다.

**제목도 같습니다.** 오히려 소개보다 중요합니다.

> "○○밴드 단독공연"을 "○○밴드 앵콜공연"으로 바꿨습니다. 단독공연인 줄 알고 산 사람이 항의합니다.

**제목은 운영진 누구나, 몇 번이든 고칠 수 있습니다.** 운영자는 가격과 초대권도 다루는데 제목만 막을 이유가 없습니다. 대신 **운영자가 제목을 바꾸면 소유자에게 알림**이 갑니다. 승인이 아니라 알기만 하는 것입니다. 판매가 끝나면 고정됩니다 (`04` 참조).

공연 직전 수정에 관리자 승인을 두지 않습니다. 관리자는 남의 공연 제목이 중요한 변경인지 판단할 수 없고 (`04` 참조), 공연 전날 밤 오타를 고치려 해도 관리자를 기다려야 하기 때문입니다.

**버전별로 기간과 함께 보관**합니다. "3/1~3/10 유효" 같은 식으로요. 예매 시각과 대조하면 어느 버전을 봤는지 알 수 있습니다.

| 이력에 남길 것 |
|---|
| 변경 일시 |
| 변경 전 내용 |
| 변경 후 내용 |
| **통지 발송 여부** |
| **누가 바꿨는지** (운영진 닉네임) |

### 보관은 행사가 끝난 날부터 6개월

전자상거래법 시행령이 **표시·광고에 관한 기록을 6개월** 보관하라고 정합니다. 행사 페이지의 제목·소개·포스터가 그 표시·광고입니다.

**6개월을 바꾼 날부터 세면 구멍이 생깁니다.**

> 1/15 — A가 예매 (공연은 10월)
> 2/1 — 제목 변경. 옛 제목 기록은 **8/1에 삭제**
> 10/14 — 공연
> 10/15 — A가 항의 → **기록이 이미 없음**

공연 몇 달 전에 예매가 열리는 건 흔합니다. **행사가 끝난 날부터 6개월**로 세면 다툼이 생기는 시점을 항상 덮습니다. 법정 최소보다 길어질 뿐 짧아지지는 않습니다.

### 블록 이름은 대상이 아닙니다

관객은 좌석을 고를 때 구역 색과 가격만 보고 번호는 보지 않습니다 (`02` 참조). 블록 이름을 "보고 샀다"는 다툼이 생길 수 없으므로 이력을 남기지 않습니다. **알림 창은 띄웁니다** (`02` 참조).

## 카테고리

유형을 고르면 그에 맞는 카테고리가 나옵니다.

| 유형 | 카테고리 |
|---|---|
| 공연 | 연극 · 뮤지컬 · 콘서트 · 클래식 · 국악 · 무용 · 코미디 · 기타 |
| 전시 | 회화 · 사진 · 미디어아트 · 설치 · 공예 · 기타 |
| 페스티벌 | 음악 · 푸드 · 문화 · 지역축제 · 기타 |

**"기타"를 고르면 장르명을 자유 입력**받습니다. 관리자가 이 목록을 주기적으로 보고, 자주 나오는 장르("낭독극" 등)를 정식 카테고리로 승격합니다.

이러면 기타가 쓰레기통이 아니라 **카테고리를 넓히는 입구**가 됩니다. 기타를 아예 없애면 주최자가 엉뚱한 카테고리를 고르는데 그게 더 나쁩니다.

## 공개 수준 3단계

| 수준 | 목록·검색 | 접근 |
|---|---|---|
| **공개** | 노출 | 누구나 |
| **링크 전용** | 노출 안 됨 | 링크를 아는 사람 |
| **암호 보호** | 노출 안 됨 | 링크 + 암호 |

사내 행사, 동호회 내부 공연, 초청 전용 공연에 필요합니다.

**초대권으로 대체할 수 없습니다.** 초대권은 무료 발권이라 **유료 내부 행사**에는 쓸 수 없습니다.

### 링크가 추측 가능하면 안 됩니다

행사 주소가 순차 번호면 **숫자를 하나씩 올려가며 비공개 행사를 전부 찾을 수 있습니다.** 비공개 행사는 추측할 수 없는 주소를 가져야 합니다.

### 전환

**판매 종료 전까지 가능**합니다. 비공개 → 공개는 그 시점부터 목록에 뜨고, 공개 → 비공개는 목록에서 사라지되 **기존 예매는 그대로 유지**됩니다.

**판매가 끝나면 고정**됩니다 (`04` 참조). 끝난 행사는 어차피 목록에서 자동으로 빠지므로 링크 전용으로 바꿔도 달라지는 게 없고, 암호를 걸면 공유된 링크가 막힙니다.

**관리자는 비공개 행사도 전부 봅니다.** 신고 대응과 제재를 위해서입니다.

## 재입장 설정

**기본값은 전 유형 OFF**입니다.

- **OFF** — 두 번째 스캔부터 경고 (`10` 참조)
- **ON** — 여러 번 찍어도 정상 통과, 입장 횟수만 기록

> ⚠️ 켜면 같은 QR로 여러 번 입장할 수 있습니다. 티켓 이미지를 공유해 여러 명이 들어오는 것을 막을 수 없으니, 팔찌나 도장 같은 현장 수단을 함께 쓰시는 걸 권합니다.

> 처음에는 유형별 기본값을 다르게(페스티벌만 ON) 주는 안이었으나, **모르고 켜지는 일**을 막기 위해 전부 OFF로 통일했습니다.

## 연령 제한

**생년월일상 나이가 모자라면 예매를 막습니다.** 경고만 하면 막는 효과가 없습니다.

> ❌ 이 공연은 만 19세 이상만 예매할 수 있습니다.

| | |
|---|---|
| 기준 나이 | **그 회차 날짜의 만 나이.** 묶음권은 첫 날 |
| 통과하면 | 예매 단계에서 필수 체크박스 |

> ☐ 본인은 만 19세 이상이며, 현장에서 신분증 확인 후 미달 시 입장이 거부되고 **환불되지 않음**에 동의합니다.

생년월일은 **자기 신고라 검증되지 않습니다.** 주최자에게 정직하게 알립니다.

> ⚠️ 연령 정보는 본인이 입력한 값이며 검증되지 않습니다. 실제 확인은 현장 신분증으로 해주세요.

## 검표 시작 시각

**회차 시작 1시간 전부터** 검표가 열립니다. 주최자가 조정할 수 있고 기본값이 1시간입니다.

**종일형은 운영 시작 시각 기준**입니다. 10시 오픈이면 9시부터 열립니다.

열리기 전에 QR을 찍으면 거부됩니다.

> ❌ 아직 입장 시간이 아닙니다
> 입장 가능: 18:00부터

**없으면 전날 미리 찍어서 입장 처리되는 사고**가 납니다. 당일에 "이미 입장함"이 떠서 관객이 못 들어가죠.

## 행사 만들기 위저드

| 단계 | 내용 | |
|---|---|---|
| 1 | 유형 · 제목 · 소개 · 포스터 · 장소 · 카테고리 (+ 상세 안내 · 지도 링크 · 공개용 연락처 선택) | 필수 |
| 2 | 회차 방식 · 회차 (날짜 · 시간 · 운영 시간 · 출연(선택)) | 필수 |
| 3 | 블록 · 구역 · 좌석 배치도 또는 정원 | 필수 |
| 4 | 가격 · 조기예매 · 쿠폰 · 묶음권 | 필수 |
| 5 | 공개 수준 · 오픈/종료 · 매수 제한 · 재입장 · 검표 시작 · 연령 제한 · 취소 규정 조정 (`08`) | 기본값 있음 |
| 6 | 입구 목록 · 검표 계정 | 판매 시작 뒤에도 입력 가능 |
| 7 | 검토 · **관객 화면 미리보기** → 판매 시작 | |

**5~6단계는 전부 기본값이 있으니 건너뛸 수 있습니다.**

**임시저장은 자동으로.** 단계를 넘길 때마다 저장되고 나갔다 들어오면 이어서 합니다. "저장" 버튼을 누르게 하면 안 누르고 나가서 다 날립니다.

**판매 시작 직전에 검증**합니다. 빠진 게 있으면 목록으로 보여주고 해당 단계로 바로 이동시킵니다.

**미리보기 링크**로 관객 화면을 확인할 수 있습니다. 그 링크로는 예매가 되지 않습니다.

### 1단계에서 장소를 입력할 때 경고

> ⚠️ **예매가 열린 뒤에는 장소를 혼자 바꿀 수 없습니다.** 관리자 승인을 거쳐야 하고, 예매자 전원에게 알림이 가며 그 표는 언제 취소해도 공제가 없습니다. 신중히 입력해 주세요.
