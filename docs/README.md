# 티켓 예매 서비스 — 기획 문서

소규모 주최자가 공연·전시·페스티벌 티켓을 직접 판매하는 웹 서비스.

**구현 착수 전 기획 회의의 결과물**이며, 코드에서 유추할 수 없는 판단과 그 이유를 담고 있습니다.

## 읽는 순서

**`14` → `02` → `07` → `00`** 순서를 권합니다.

`14`가 전체 관계도이고, `02`의 날짜·회차·구역·블록 모델과 `07`의 티켓 개념이 **거의 모든 문서에 걸쳐 있습니다.** 이 셋을 모르면 가격도 검표도 환불도 이해되지 않습니다.

**왜 그렇게 정했는지**가 궁금하면 `15`의 세 사람(한서윤·박정훈·이도현)을 보십시오. 문서 곳곳의 "(`15` 박정훈)" 같은 표시가 그 근거입니다.

## 핵심 개념

| 개념 | 뜻 |
|---|---|
| **도면** | 블록·좌석·구역·입구. **행사에 하나.** 회차와 무관 |
| **날짜 → 회차** | 관객이 고르는 "언제". **재고는 회차에만** 붙음 |
| **구역** | 가격이 붙는 재고 묶음 (R석, 스탠딩A) |
| **블록** | 좌석 번호를 매기는 물리적 덩어리 (1층, 2층) |
| **티켓** | QR 1개 = 입장 1명. **회차 1개 이상을 가리킴** |

**구역과 블록은 다릅니다.** 구역은 가격, 블록은 번호입니다. 한 구역이 여러 블록에 걸칠 수 있고 그 반대도 됩니다.

**도면과 재고는 다릅니다.** 좌석은 하나, 판매 상태는 회차마다입니다.

## 중요

각 결정에는 **이유가 함께 적혀 있습니다.** 회의 중 뒤집힌 결정은 "처음에는 이랬으나 이래서 바꿨다"까지 남겼습니다. 결론만 보고 바꾸면 이미 배제한 선택지로 되돌아가게 됩니다.

**단계를 나누지 않습니다.** MVP도 2단계도 없고, 문서에 적힌 것은 전부 만듭니다.

`99-decisions.md`의 **"만들지 않기로 한 것"** 은 의도적 제외입니다. 없는 기능에도 결정이 있습니다.

## 구현 시작할 때 CLAUDE.md에 넣을 내용

> 레포 골격(`ticket-on/`)의 `CLAUDE.md`와 `.claude/rules/`에 이미 반영했습니다. 아래는 원본입니다.

```markdown
## 기획 문서
- 모든 기능 명세는 `docs/` 아래에 있다. 기능을 구현하기 전에 해당 문서를 읽는다.
- 전체 관계도는 `docs/14-domain-model.md`다. 가장 먼저 읽는다.
- 핵심 모델은 `docs/02-event-model.md`와 `docs/07-ticket.md`다. 그 다음 읽는다.
- 문서에 적힌 기능은 전부 만든다. "MVP"나 "나중에"로 미루거나 임시로 대충 만들지 않는다.
- `docs/99-decisions.md`의 "확인 과제"는 외부 확인(법 조문 등)이 필요한 사항이다. 추측하지 말고 사용자에게 묻는다.
- `docs/99-decisions.md`의 "만들지 않기로 한 것"은 의도적 제외다. 임의로 추가하지 않는다.
- 문서에 없는 판단이 필요하면 `docs/15-personas.md`의 세 사람에게 어떻게 닿는지 보고, 정하기 전에 사용자에게 묻는다.
- 정책·규칙은 문서가 기준, 화면은 Figma(https://www.figma.com/design/LUBGZagmOrFkLjX892hEUT)가 기준이다. 둘이 다르면 임의로 정하지 말고 묻는다.

## 구조
- 기술 스택과 구조는 `docs/16-architecture.md`를 따른다.
- 모듈 의존은 안쪽으로만: domain ← application ← app-*, infra-*. domain에는 Spring·jOOQ를 넣지 않는다.
- 포트(들어오는·나가는)는 application이 가진다. 어댑터는 포트를 부르거나(들어오는 쪽) 구현한다(나가는 쪽).
- 포트의 입출력은 Command/Query/Result로 정한다. Request/Response를 안쪽으로 넘기지 않는다.
- 도메인 패키지는 `16`의 층 순서대로 위에서 아래로만 부른다. ArchUnit 테스트로 검사한다.
- 읽기 전용 조회(현황·통계·정산)는 도메인을 거치지 않고 바로 DTO로 꺼낸다.
- common에는 순수 유틸만 둔다. 설정은 넣지 않는다.
```
