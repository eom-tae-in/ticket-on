# 13. 화면 구성 (IA)

다섯 영역입니다.

## 1. 공개 영역 — 로그인 불필요

```
홈 · 행사 목록
 └─ 행사 상세
     ├─ 소개 · 포스터 · 장소 · 운영 시간
     ├─ 회차(날짜) 목록
     ├─ 가격 안내 (구역별 · 조기예매 임박)
     ├─ 잔여 수량
     ├─ 연령 제한 표시
     ├─ 취소·환불 규정
     ├─ 주최자명 → 주최자 페이지
     ├─ 주최자 공개 연락처 (입력한 경우)
     ├─ 판매자 정보  사업자: 상호·대표자·주소·전화·사업자등록번호 / 비사업자: 안내 문구 (`01`)
     ├─ [예매하기] → 로그인
     ├─ [알림 받기]  ※ 오픈 전, 로그인 필요
     └─ [신고]       ※ 누르면 로그인

모든 페이지 하단 — 운영자 정보 · 통신판매중개자 고지 · 이용약관 · 개인정보처리방침 (`01`)

주최자 페이지 (`01`)
 ├─ 주최자명 · 소개 · SNS 링크   ※ 닫혔으면 "활동 종료" 배지
 ├─ 운영진 닉네임 → 운영진 프로필
 ├─ 진행 중 행사
 └─ 지난 행사   ※ 비공개·전부 취소·내려간 행사는 빠짐

운영진 프로필 (`01`)
 ├─ 닉네임 · 한 줄 소개
 └─ 참여한 주최자 (이름 · 역할 · 기간) → 주최자 페이지

링크로만 여는 페이지 — 로그인 불필요, 주소는 추측 불가
 ├─ 공유받은 티켓 (`07`)            QR 1장 · 무효면 이유 표시
 ├─ 초대권 — 단체 / 개별 (`09`)     목록 · 넘기기 모드 · 회수·취소된 줄은 회색
 ├─ 마케팅 수신 거부 (`12`)         한 번에 처리, 결과 표시
 └─ 삭제·내려간 행사                "삭제된 행사입니다" / "운영 정책에 따라 비공개 처리된 행사입니다"

로그인 / 회원가입
 ├─ 일반 로그인  ── "주최자 로그인" 링크
 ├─ 회원가입 (직접 / OAuth)  ※ "필수 항목 모두 동의" + 마케팅은 따로 (`01`)
 │   └─ 전화번호 중복이면 "이미 가입된 번호입니다. 본인 번호가 맞다면 문의해 주세요"
 ├─ 추가 정보 입력  ※ OAuth 가입 시 (전화번호 중복 확인 동일)
 └─ 비밀번호 찾기  ※ 관객 / 주최자 중 고름 · 가입 여부와 상관없이 같은 안내 (`01`)
```

**행사 상세를 공개로 두는 게 핵심**입니다. 주최자가 링크를 뿌리는 게 주된 홍보 수단입니다.

**비공개 행사**는 목록·검색에 뜨지 않고 링크(+암호)로만 접근합니다 (`03` 참조).

### 목록 화면

**정렬**

| 정렬 | 기준 |
|---|---|
| **공연일순** (기본) | 가까운 날짜부터 |
| 최신 등록순 | 새로 올라온 것 |

**조회순은 넣지 않습니다.** 조작이 쉽고(새로고침만 해도 오름), 고착되며(상위 노출 → 더 많은 조회 → 더 상위), 행사 수가 적으면 무의미합니다. 그리고 조회는 관심이지 인기가 아닙니다.

판매율순과 "최근 24시간 판매량"은 만들지 않습니다 (`99` B 참조).

**잔여 좌석 표시**

| 화면 | 표시 |
|---|---|
| **목록 카드** | 임박할 때만 배지 |
| **행사 상세** | 잔여 수량 표시 |

- 잔여 10% 이하 또는 10석 이하 → **매진 임박**
- 잔여 0 → **매진**
- 그 외 → 표시 없음

**"480석 남음"을 목록에 띄우면 안 됩니다.** 소규모 행사는 대부분 여유가 있는데, 그걸 박아두면 모든 카드가 "안 팔리는 공연"처럼 보입니다.

**상세에서는 알려줘야 합니다.** 잔여가 3석인데 4매를 고르려 하면 막히는데, 이유를 모르면 답답합니다. (조기예매의 남은 몫은 정확한 숫자 대신 임박 단계로만 보여줍니다, `05` 참조)

**판매 중단 상태**는 목록에 그대로 두되 "판매 일시 중단"으로 표시합니다 (`04` 참조).

**필터와 검색**

- **유형 필터** (공연/전시/페스티벌) — 필수
- **카테고리 필터** — 유형 안에서 (`03` 참조)
- **검색** — 행사명, 주최자명
- 지역 필터는 만들지 않습니다 (`99` B 참조)

## 2. 관객 영역

```
예매
 ├─ 회차 선택 (또는 날짜 · 묶음권)  ※ 연령 미달이면 여기서 막힘 · 이용 정지면 [예매하기]에서 막힘
 ├─ 좌석 선택  ← 타이머 10분 시작 · 구역 색과 가격만 표시
 │   또는 매수 선택  ← 수량형
 ├─ 쿠폰 입력
 ├─ 예매자 정보 확인  ※ 계정 정보 자동
 ├─ 동의 (취소 규정 · 연령 · 좌석 속성)
 ├─ 결제  ← 결제창을 여는 순간 타이머 7분 다시 시작 · 결제 버튼 위 통신판매중개자 고지 한 줄 (`01`)
 └─ 완료 · 티켓 발급

마이페이지
 ├─ 예매 내역 (예매 카드 = 행사별)
 │   ├─ 다가오는 예매
 │   ├─ 지난 예매  ← 공연이 끝났거나 전부 취소된 카드
 │   └─ 예매 카드
 │       ├─ 총 N장
 │       ├─ 예매 건별 분리
 │       │   ├─ 티켓 목록 (QR · 공유 · 넘기기)
 │       │   ├─ 좌석·회차 변경
 │       │   ├─ 취소  ← 고른 만큼 즉시 자동 환불. 여러 예매 건을 한 화면에서 골라도 됨 (`08`)
 │       │   ├─ 출연자 변경된 날 포기  ※ 묶음권, 해당할 때만 (`04`)
 │       │   └─ QR 재발행 신청
 │       └─ 결제·환불 내역
 ├─ 알림함  ※ 처음 본 알림만 굵게 · 탭 배지 없음 (`12`)
 ├─ 알림 설정 · 마케팅 수신
 ├─ 알림 신청 목록
 └─ 계정 정보 · OAuth 연동
     ├─ 전화번호 변경  ※ 다른 계정이 쓰는 번호면 불가
     └─ 회원 탈퇴      ※ 공연 전 티켓이 있으면 막힘 (`01`)
```

### 예매 내역은 행사로 묶고 예매 건으로 나눕니다

```
○○밴드 단독공연 · 3월 14일 19:00
총 4장                                    ← 유효한 것만 셈

┌─ 예매번호 ...0091 · 3/1 예매 ───────────────┐
│  R석 12열 7번    [QR] [공유]                  │
│  R석 12열 8번    [QR] [공유]                  │
│  실 결제액 100,000원       [결제·환불 내역]    │
└─────────────────────────────────────────┘

┌─ 예매번호 ...0134 · 3/5 예매 ───────────────┐
│  R석 15열 3번    [QR] [공유]                  │
│  A석 20열 1번    [QR] [공유]                  │
│  ───────────────────────────                 │
│  R석 15열 4번    취소됨 · 좌석 변경            │  ← 회색, 버튼 없음
│  실 결제액 80,000원        [결제·환불 내역]    │
└─────────────────────────────────────────┘
```

**행사는 묶는 단위, 예매 건은 보여주는 단위**입니다.

상단에 "총 4장"이 있어 전체가 한눈에 들어오고, 아래는 예매 건별로 나뉘어 **"3월 5일에 산 것 중 하나를 바꿨다"가 명확**합니다. 합쳐두면 환불 기록이 한 줄로 쌓여서 어느 예매에서 나온 건지 역추적해야 합니다.

**정렬은 예매일 순**입니다.

**취소된 티켓도 카드에 남습니다.** 유효한 티켓은 위에, 취소된 티켓은 아래에 회색으로 두고 사유를 붙입니다 (`07` 참조). 주최자가 회차를 취소하는 등 **관객이 직접 하지 않은 취소**도 예매 내역을 열면 바로 알 수 있습니다.

**카드에는 실 결제액만** 둡니다. 결제와 환불이 오간 내역은 [결제·환불 내역]에서 봅니다. 변경할 때마다 환불·결제 두 줄이 생기므로 카드에 다 적으면 금방 길어집니다.

**전부 취소한 행사**도 **카드는 남습니다.** 모든 줄이 회색이고 "지난 예매" 쪽으로 내려갑니다. **공연이 모두 끝난 카드**도 "지난 예매"로 내려갑니다 (`04` 참조).

**내가 산 표만 나옵니다.** 초대권이나 친구에게 공유받은 표는 받은 사람이 가입해 있어도 여기 나오지 않고 링크 페이지에서만 봅니다 (`09` 참조).

### 좌석 선택 화면 — 모바일 필수

관객 대부분이 폰으로 예매하므로 타협 없이 잘 돌아가야 합니다.

- **핀치 줌 · 팬** 필수. 200석을 작은 화면에 다 띄우면 좌석이 몇 픽셀이 됩니다
- 탭하면 선택, 다시 탭하면 해제
- **하단에 선택 목록과 가격 합계 고정**
- 남은 시간 타이머도 여기 표시
- **구역은 색으로 구분**하고 범례를 둠. 좌석 번호는 표시하지 않음 (`02` 참조)
- 좌석 속성(휠체어·시야제한)은 아이콘과 색으로 구분

## 3. 주최 관리

```
로그인
 ├─ 소속된 주최자가 없으면 → 새 주최자 신청 / 받은 초대 / 닫힌 주최자 다시 열기 신청 (소유자였던 경우)
 ├─ 신청이 심사 중이면 → "심사 중" 화면만 (`01`)
 └─ 여러 곳에 소속돼 있으면 → 주최자 전환

내 행사 목록
 ├─ 작성 중 구역 (진행률 · 마지막 수정일 · [이어서 작성])
 ├─ 진행 중 행사 (판매 대기 · 판매 중 · 판매 종료)
 └─ 지난 행사 (행사 종료 · 정산 완료 · 취소됨) — 복제 가능, 편집 불가. 삭제는 팔린 표·초대권이 없었던 행사만
 │
 ├─ 행사 만들기 (위저드 7단계 · 자동 임시저장)
 │   1. 유형 · 제목 · 소개 · 포스터 · 장소 · 카테고리 (+ 상세 안내 · 지도 링크 · 공개용 연락처)
 │   2. 회차 방식 · 회차 (날짜 · 시간 · 운영 시간 · 출연(선택))
 │   3. 블록 · 구역 · 좌석 배치도 또는 정원
 │   4. 가격 · 조기예매(상품별 적용) · 쿠폰 · 묶음권
 │   5. 공개 수준 · 오픈/종료 · 매수 제한 · 재입장 · 검표 시작 · 연령 제한 · 취소 규정 조정
 │   6. 입구 목록 · 검표 계정
 │   7. 검토 · 미리보기 → 판매 시작
 │
 ├─ 행사 복제
 │
 └─ 행사 운영
     ├─ 수정 (예매가 열린 뒤 수정 범위, `04`)
     │   ├─ 큰 변경이면 "예매자에게 알릴까요?" 창
     │   ├─ 회차 추가 · 회차 시간 수정 (그 회차 시작 1주일 전까지)
     │   └─ 블록 이름 변경
     ├─ 예매 현황 (오늘 판매 수 · 연령대 통계 — 행사·회차별, 예매자 30명 이상, `11`)
     ├─ 입장 현황 (티켓 없이 입장한 인원 포함)
     ├─ 관계자석 · 초대권 (개별 / 단체 발권, 판매 대기부터 회차가 끝날 때까지. 판매 대기 발권 시 확인 창)
     │   └─ 직접 알려야 할 초대권 N건
     ├─ 검표 계정
     ├─ 검표 화면 열기  ← 운영진도 같은 화면 + [티켓 없이 입장 처리]
     ├─ 정산 (배상 · 지연 환급 · 미수금 표시)
     ├─ 판매 중단·재개  ※ 관리자가 멈췄으면 재개 불가 표시
     ├─ 연기 신청 / 장소 변경 신청 (배치가 다르면 새 도면 + 재배정 안)
     ├─ 관리자 수정 요청이 있으면 상단 안내 + [수정 완료]
     ├─ 출연자 변경 알림 · 공연 지연 처리  ※ 소유자만
     ├─ 공연 중단 처리 · 회차 취소 · 행사 취소 (사유: 주최자 사정 / 불가항력)  ※ 소유자만
     └─ 행사 삭제  ※ 팔린 표·초대권이 없었을 때만. 판매 시작 후는 소유자만

내 프로필 — 닉네임 · 한 줄 소개 편집 ([랜덤 생성])

운영진 관리
 ├─ 운영진 목록 (소유자 · 운영자)
 ├─ 운영자 초대 · 내보내기       ※ 소유자만
 ├─ 소유자 넘기기 (운영자에게만) ※ 소유자만
 ├─ 소유자 이전 신청             ※ 운영자. 소유자와 연락이 끊긴 경우 관리자에게 (`11`)
 └─ 이 주최자에서 나가기          ※ 운영자

주최자 공개 정보 — 소개 · SNS 링크 · 로고(선택, 없으면 첫 글자 + 정해진 색)  ※ 운영진 누구나

주최자 정보 · 사업자 정보 · 정산 계좌   ※ 소유자만. 사업자 정보·계좌 변경은 관리자 확인 후 적용
 ├─ 주최자명 변경                 ※ 소유자만. 바로 적용, 이력 남음 · 운영진·관리자에게 알림
 └─ 주최자 닫기                   ※ 소유자만. 정산 안 끝난 행사·미수금이 없을 때
```

**운영자에게는 소유자 전용 메뉴를 감춥니다.** 눌러도 안 되는 버튼을 보여주면 "왜 안 되냐"는 문의만 생깁니다.

**5~6단계는 기본값이 있어 건너뛸 수 있습니다.** 판매 시작 직전에 검증하고, 빠진 게 있으면 해당 단계로 바로 이동시킵니다.

### 좌석 배치도 에디터 — 데스크톱 우선

```
블록 추가 → 이름 입력 → 행×열 지정
  → 블록 이동 · 회전
  → 개별 좌석 비활성화
  → 좌석을 구역에 배정 (색칠)
  → 좌석 속성 지정
  → 무대 위치
```

모바일에서도 열리되 템플릿 선택·블록 추가·구역 배정까지는 편하게, 개별 좌석 토글은 줌인이 필요하다고 안내합니다 (`02` 참조).

## 4. 검표 — 모바일·태블릿

```
검표 로그인 → 입구 선택 → 스캔 화면
                            ├─ 연령 제한 행사면 상단에 "신분증 확인" 고정 배지
                            ├─ 결과 표시 (좌석 크게) — 결과 종류는 `10` "결과 화면"
                            │   └─ 신호: 화면 색 기본 · 소리 기본 켬(기기마다 끔) · 진동은 되는 기기만 (`10`)
                            ├─ 중복 경고 + [그래도 입장]
                            ├─ 수동 검색 (이름 + 뒷 4자리 → 전화번호 전체)
                            │   └─ 못 찾으면 "현장 책임자를 불러주세요"
                            ├─ [티켓 없이 입장 처리]  ※ 운영진 로그인일 때만
                            └─ 입구 변경
```

**한 화면에 스캐너와 수동 검색이 같이** 있어야 합니다.

## 5. 플랫폼 관리자

```
처리 목록 — 아래 요청이 한곳에 쌓임. 공연 임박 건 강조 (`12`)
 ├─ 주최자 신청       → 심사 (체크리스트 · 승인/반려)
 │                     같은 소유자·단체명의 닫힌 주최자가 있으면 함께 표시 → "다시 열기"로 돌릴 수 있음
 ├─ 닫힌 주최자 다시 열기 신청 → 심사 (이력 이어짐)
 ├─ 주최자명 변경 (사후 확인)
 ├─ 연기 · 장소 변경 승인 (장소는 재배정 안 확인)
 ├─ QR 재발행        → 처리 / 반려 (사유)
 ├─ 신고             → 수정 요청 / 페이지 내리기 / 지연·출연자 변경 대신 처리 / 정지 단계 / 문제 없음
 │                     (신고자에게 결과 한 줄)
 ├─ 불가항력 확인     → 배상 면제 / 지급
 ├─ 소유자 이전 신청  ※ 소유자와 연락이 끊긴 경우
 ├─ 정산 계좌 · 사업자 정보 변경 확인
 ├─ 비사업자 주최자 정보 제공  ※ 분쟁조정기구·법원 요청 또는 주최자 동의 시 (`01`)
 ├─ 미수금 납부 확인
 ├─ 수정 요청에 대한 주최자의 [수정 완료] 확인
 └─ 예매 대신 취소 문의 (오류 구제, `08`)

주최자 목록      → 상세 (운영진 · 행사 이력 · 취소 이력 · 소유자 변경 이력 · 미수금) · 닫힌 주최자 포함
                   · 정지 1~3단계 (2·3단계는 대상 행사 선택) · 4단계 영구 정지 ※ 최고 관리자만 · 해제
                   · 부적절한 주최자 로고 초기화
행사 목록        → 비공개 행사 포함 전체 · 행사 페이지 내리기 / 다시 올리기
예매 찾기        → 예매번호 · 이메일로 검색 → 대신 취소 (`08`)
사용자 찾기      → 이메일 · 전화번호로 검색 → 이용 정지 / 해제 (`01`)
운영진 찾기      → 닉네임 · 이메일로 검색 → 소속 이력 (지금·과거 · 역할 · 기간) → 누르면 주최자 상세
                   · 부적절한 닉네임 · 소개 초기화
카테고리 "기타" 자유 입력 목록 → 정식 카테고리 승격
정산 완료 처리
마케팅 발송       → 동의자 대상 이메일. 제목 "(광고)" 자동, 수신 거부 링크 포함
차단 목록         → 영구 정지 주최자(재가입 수동 대조) · 가담 운영자 개인 차단 · 이용 정지 후 탈퇴한 번호
관리자 계정 발급   ※ 최고 관리자만
```

**모든 조작에 "누가 언제 무엇을"이 기록됩니다** (`01` 참조).
